# ⚔ ReaperZone

Un jeu de tir top-down avec 5 modes de jeu, une IA avancée et un système d'upgrades.

## 🎮 Jouer
👉 [Cliquez ici pour jouer](https://whyalwaysme83.github.io/ReaperZone)

## Modes de jeu
- 🎯 **Classique** — Vagues infinies + upgrades d'armes
- ⏱ **Speedrun** — Termine 10 vagues le plus vite possible
- 💀 **Horde** — Ennemis non-stop, score pur, pas d'upgrade
- 👑 **Boss Rush** — Enchaîne les boss sans relâche
- 🛡 **Défense** — Protège la zone centrale contre les vagues

## Contrôles
| Touche | Action |
|--------|--------|
| Z Q S D | Déplacer |
| Souris | Viser |
| Clic gauche | Tirer |
| Espace | Dash / Esquive |
| Échap | Menu |

## Ennemis
- 🔴 Grunt — Suit et alerte ses alliés
- 🟠 Speeder — Rapide, flanque par les côtés
- 🟣 Tank — Lent mais très résistant
- 🟢 Shooter — Garde ses distances et tire
